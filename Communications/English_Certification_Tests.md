## 🔍 Detailed Overview of Each Platform

### 1. 🎓 [EF SET (EF Standard English Test)](https://www.efset.org/)
* **Website:** [https://www.efset.org/](https://www.efset.org/)
* **Highlights:**
  * The only completely free, standardized English test that provides a shareable URL and certificate directly addable to your **LinkedIn Licenses & Certifications** section.
  * Rigorously aligned to the Common European Framework of Reference (CEFR: A1 to C2).
  * Two test modes available:
    * **50-Minute EF SET Certificate:** Comprehensive reading and listening evaluation with an official score report.
    * **15-Minute Quick Check:** Rapid reading and listening score estimate.

## 📊 CEFR Level Reference Guide

| Level | Classification | Professional Workplace Capability |
| :---: | :--- | :--- |
| **C2** | Mastery / Native-level | Can understand virtually everything heard or read; expresses effortlessly with high nuance in client-facing executive conversations. |
| **C1** | Effective Operational Proficiency | Can express ideas fluently and spontaneously; conducts technical deep dives and big-4 client presentations without hesitation. |
| **B2** | Vantage / Independent User | Can interact with native speakers with fluency; writes clear technical documentation, code comments, and participates actively in agile standups. |
| **B1** | Threshold / Intermediate | Can understand main points of standard business input; handles routine technical correspondence and day-to-day work tasks. |
