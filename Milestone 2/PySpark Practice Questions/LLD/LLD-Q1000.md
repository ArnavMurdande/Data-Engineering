# SmartCity Mobility Mega Assessment (Q1000)

## How to run

```bash

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt

python3 test_runner.py

```

This will:

- run the tests defined in `test_config.json`

- load your functions from `solution.py`

- print `[PASS]` / `[FAIL]` per test case

- write results to `test_report.log`

## Dataset

CSV files are provided in `data/`:

- `data/mobility_trips.csv`

- `data/vehicles.csv`

- `data/users.csv` (for your own practice; tests use inline profiles/plans too)

`mobility_trips.csv` columns:

- trip_id (string)

- user_id (string)

- vehicle_id (string)

- zone (string)

- trip_date (string `yyyy-MM-dd`)

- start_ts (string `yyyy-MM-dd HH:mm:ss`)

- end_ts (string `yyyy-MM-dd HH:mm:ss`)

- distance_km (double)

- fare (double)

- discount (double)

- payment_method (string)

- vehicle_type (string)

- speed_kmh (double)

- harsh_brake_count (int)

- status (string: Completed/Cancelled)

## Objective

Implement **40 pure PySpark functions** in `solution.py`.

### Important testing note (no dependency)

Each function is tested **independently**.

For functions that normally depend on upstream cleaning/aggregation, the tests pass a **precomputed DataFrame** fixture.

A) Core Trip Analytics (1–20)

1) define_trip_schema() -> StructType

Goal: Explicit schema for mobility_trips.csv with all nullable fields.

Flow:

Create a StructType with fields in the same order as CSV columns.

Keep:

trip_date, start_ts, end_ts as string.

numeric fields as double/int as specified.

Return schema.

2) load_trips(spark, path, schema) -> DataFrame

Goal: Load CSV with header and your schema.

Flow:

Use Spark CSV reader with:

header enabled

schema applied

Return DataFrame.

3) parse_trip_date(df) -> DataFrame

Goal: Convert trip_date string to DateType.

Flow:

Replace/overwrite trip_date column using date parsing.

Return updated DF.

4) add_trip_duration_min(df) -> DataFrame

Goal: Add integer trip duration in minutes.

Flow:

Convert start_ts and end_ts to epoch seconds.

Compute (end - start) / 60.

Round as required by spec (or floor if tests expect it—spec says integer minutes; most consistent is rounding to nearest then cast).

Add new column: trip_duration_min as int.

Return DF.

5) add_cost_per_km(df) -> DataFrame

Goal: Add cost_per_km = fare / distance_km.

Flow:

Create new column cost_per_km as double.

(Optionally handle distance_km = 0 → null/inf; tests usually avoid zero.)

Return DF.

6) filter_peak_hour_trips(df) -> DataFrame

Goal: Keep trips starting in peak hours: 07–10 OR 17–20 inclusive.

Flow:

Extract hour from start_ts.

Filter where hour is in either range (inclusive).

Return filtered DF.

7) top_n_users_by_distance(df, n) -> DataFrame

Goal: Top users by total distance.

Flow:

Group by user_id.

Aggregate sum of distance_km as total_distance_km.

Order:

total_distance_km desc

user_id asc

Limit to n.

Return DF.

8) avg_speed_by_zone(df) -> DataFrame

Goal: Average speed per zone.

Flow:

Group by zone.

Compute average of speed_kmh as avg_speed_kmh.

Return DF.

9) most_common_vehicle_type(df) -> str

Goal: Most frequent vehicle_type (tie-break asc).

Flow:

Group by vehicle_type, count rows.

Order by:

count desc

vehicle_type asc

Take first row.

If DF empty → return "".

Return string vehicle_type.

10) cancellation_rate_by_zone(df) -> DataFrame

Goal: cancelled/total per zone.

Flow:

Group by zone.

Compute:

total count

cancelled count using conditional sum where status == "Cancelled"

Compute cancellation_rate = cancelled / total as double.

Select only: zone, cancellation_rate.

Return DF.

11) high_duration_trips(df, threshold_min) -> DataFrame

Goal: duration > threshold.

Flow:

If trip_duration_min missing:

compute it (same logic as function 4)

Filter where trip_duration_min strictly greater than threshold.

Return DF.

12) count_active_vehicles_by_zone(vehicles_df) -> DataFrame

Goal: Count active vehicles per home zone.

Flow:

Filter vehicles where status == "Active".

Group by home_zone.

Count distinct vehicle_id as active_vehicles.

Rename home_zone → zone.

Return DF.

13) daily_net_revenue_trend(df) -> DataFrame

Goal: Daily sum of (fare - discount).

Flow:

Create net_revenue = fare - discount (double).

Group by trip_date.

Sum net_revenue as daily_net_revenue.

Order by trip_date asc.

Return DF.

14) top_vehicle_by_net_revenue(df) -> Tuple[str, float]

Goal: Vehicle with highest total net revenue.

Flow:

Compute net_revenue per row (fare - discount).

Group by vehicle_id, sum net_revenue as total_net_revenue.

Order by:

total_net_revenue desc

vehicle_id asc

Take first:

If empty → return ("", 0.0)

Else return (vehicle_id, total_net_revenue) with float conversion.

15) list_zones(df) -> List[str]

Goal: Unique zones sorted ascending.

Flow:

Select distinct zones.

Collect to driver as list.

Convert values to strings (safe).

Sort in Python.

Return list.

16) trips_in_date_range(df, start, end) -> DataFrame

Goal: trip_date between start and end inclusive.

Flow:

Ensure comparison uses DateType values:

Convert start/end strings into date literals.

Filter with inclusive between.

Return DF.

17) flag_safety_risk(df, speed_threshold, brake_threshold) -> DataFrame

Goal: Add boolean is_risky.

Flow:

is_risky = (speed_kmh > threshold) OR (harsh_brake_count > threshold)

Add column is_risky boolean.

Return DF.

18) top_n_risky_vehicles(df, n) -> DataFrame

Goal: Count risky trips per vehicle.

Flow:

Filter where is_risky == True.

Group by vehicle_id.

Count rows as risky_count.

Order:

risky_count desc

vehicle_id asc

Limit n.

Return DF.

19) avg_fare_by_payment_method(df) -> DataFrame

Goal: Avg fare per payment method.

Flow:

Group by payment_method.

Aggregate avg(fare) as avg_fare.

Return DF.

20) get_longest_trip(df) -> Tuple[str, int]

Goal: Longest by duration, tie trip_id asc.

Flow:

Ensure duration exists (compute if missing).

Order:

trip_duration_min desc

trip_id asc

Select trip_id and duration.

If empty → ("", 0)

Return (trip_id, trip_duration_min).

D) Additional analytics (28–40)

28) revenue_share_by_vehicle_type(metrics_df) -> List[str]

Input: columns vehicle_type, rev

Goal: Return vehicle_types ordered by revenue share desc.

Flow:

Group by vehicle_type, sum rev as total_rev.

Compute grand total (sum of total_rev).

Edge case:

if grand is null/0 → return []

Add share = total_rev / grand_total.

Order:

share desc

vehicle_type asc (tie-break)

Collect ordered vehicle_type into Python list and return.

29) busiest_zone_by_trips(df) -> Tuple[str, int]

Goal: Zone with max trip count.

Flow:

Group by zone, count rows.

Order:

count desc

zone asc

Take first:

empty → ("", 0)

Return (zone, count).

30) completed_trips_by_zone(df) -> DataFrame

Goal: Count completed trips per zone.

Flow:

Filter status == "Completed".

Group by zone, count as completed_trips.

Order:

completed_trips desc

zone asc

Return DF.

31) add_utilization_score(df) -> DataFrame

Goal: utilization_score = distance_km * trip_duration_min.

Flow:

Ensure trip_duration_min exists (compute if missing).

Create utilization_score as double.

Return DF.

32) top_n_users_by_utilization(df, n) -> DataFrame

Goal: Top users by total utilization.

Flow:

Ensure utilization_score exists (compute if missing).

Group by user_id, sum utilization_score as total_utilization.

Order:

total_utilization desc

user_id asc

Limit n.

Return DF.

33) median_duration_by_zone(df) -> DataFrame

Goal: Median trip duration per zone.

Flow:

Ensure trip_duration_min exists.

Group by zone.

Use approximate median aggregation (percentile_approx at 0.5).

Alias column median_duration_min.

Return DF.

34) minmax_normalize_fare(df) -> DataFrame

Goal: fare_norm = (fare - min) / (max - min).

Flow:

Compute global min(fare) and max(fare) by aggregating once to driver.

Edge case:

if min/max missing OR max == min → add fare_norm = 0.0 for all rows.

Else compute normalized value per row.

Return DF.

35) detect_outlier_fares(df) -> DataFrame

Goal: is_outlier if fare > mean + 2*stddev_pop.

Flow:

Aggregate global mean and stddev_pop of fare (collect once).

If mean or stddev missing → set is_outlier False.

Else compute threshold and add boolean column is_outlier.

Return DF.

36) monthly_net_revenue_by_zone(df) -> DataFrame

Goal: Sum net revenue by month+zone.

Flow:

Ensure trip_date is DateType (tests may already provide it; don’t force parse unless needed).

Compute net_revenue = fare - discount.

Compute month string formatted yyyy-MM.

Group by (month, zone), sum net_revenue as monthly_net_revenue.

Order by month asc, zone asc.

Return DF.

37) weekday_peak_trip_counts(df) -> DataFrame

Goal: Peak trips count per weekday label.

Flow:

Get peak-hour trips (reuse same filtering logic as function 6).

Extract weekday label from trip_date (e.g., Mon/Tue…).

Group by weekday, count as peak_trips.

Return DF.

38) pivot_payment_counts_by_zone(df) -> DataFrame

Goal: Pivot counts by payment method for each zone.

Flow:

Group by zone.

Pivot on payment_method.

Aggregate count.

Fill nulls with 0 (so zones missing a method get 0).

Return pivoted DF.

39) calculate_net_revenue(df) -> DataFrame

Goal: Add net_revenue = fare - discount.

Flow:

Add/overwrite net_revenue as double.

Return DF.

40) flag_service_due(vehicles_df, due_days) -> DataFrame

Goal: is_service_due based on last_service_date.

Flow:

Compute days since last service: datediff(current_date, last_service_date).

is_service_due = diff > due_days.

Add boolean column is_service_due.

Return DF.

Practical tips to avoid FAILs

Always alias exactly as specified (total_distance_km, avg_speed_kmh, daily_net_revenue, etc.).

Apply tie-break sorting even when it feels unnecessary.

For tuple returns, always handle empty input safely.

Don’t mutate input variables in surprising ways—return new DF each time.
