LLD & ERD Summary: Illustrates the Kimball Star Schema in `gold_schema`. Raw PII is completely eliminated in favor of cryptographic SHA-256 keys, and dimensions link to facts via deterministic surrogate hash keys (`xxhash64`).

Quality Architecture 
flowchart TD
    B["Raw Record from Bronze Table"] --> PREP["Prepare Record:
1. Trim whitespace on string columns
2. Retain _raw_record JSON snapshot"]
    PREP --> CAST["Apply Strict Data Type Casting:
• ISO string to Timestamp
• Integer floor and capacity
• Date effective_date"]

    CAST --> C_CAST{"Type cast succeeded?"}
    C_CAST -->|No: Rule DQ002| REJ["Quarantine to silver_rejected_records
• Record rule_id DQ002
• Failure reason
• Preserve raw_record and source_file"]

    C_CAST -->|Yes| C_REQ{"Passes Rule DQ001?
Mandatory fields non-null and non-empty?"}
    C_REQ -->|No: Rule DQ001| REJ

    C_REQ -->|Yes| C_CAT{"Passes Rule DQ003?
Categorical code in allowed clinical domain?
e.g. triage in P1, P2, P3, P4"}
    C_CAT -->|No: Rule DQ003
24 UNKNOWN_CODE records| REJ

    C_CAT -->|Yes| C_NUM{"Passes Rule DQ004?
Non-negative floor, capacity at least 1?"}
    C_NUM -->|No: Rule DQ004| REJ

    C_NUM -->|Yes| C_TIME{"Passes Rule DQ005?
Chronology valid?
discharge after admission, result after order"}
    C_TIME -->|No: Rule DQ005| REJ

    C_TIME -->|Yes| DEDUP{"Is record an exact duplicate?
Business-record comparison across all columns"}
    DEDUP -->|Yes: Exact Duplicate| DUP_AUDIT["Audit to silver_duplicate_audit
• 47 duplicate records isolated
• Kept copy selected by latest ingestion"]

    DEDUP -->|No: Unique Record| CLEAN["Write to Curated Silver Delta Tables
• silver_patient_encounters: 12,305 rows
• silver_lab_test_events: 758 rows
• silver_bed_transfer_events: 392 rows
• silver master tables: 183 / 192 / 201"]

    CLEAN --> REF_CHECK["Rules DQ007 and DQ008 Consistency Check:
• Foreign key orphan validation
• Event inside parent encounter lifecycle
Note: Flagged as WARN, reported for review, not deleted"]
Silver DQ Logic: Shows the deterministic quarantine and deduplication rules ensuring zero silent data loss. Reconciles 12,376 Bronze encounters = 12,305 Silver encounters + 24 rejected + 47 duplicates.
